## ✦ Como Executar o Projeto Localmente

Como o projeto utiliza tecnologias web nativas e WebGL para a renderização do elemento 3D, recomenda-se executá-lo através de um servidor HTTP local:

### Opção 1: Com Python (já disponível no ambiente)
No terminal, dentro da pasta `portfolio`:
```bash
python -m http.server 3000
```
Em seguida, abra o navegador em: `http://localhost:3000`

### Opção 2: Com VS Code / Antigravity (Live Server)
Clique com o botão direito em `index.html` e selecione **"Open with Live Server"**.

### Opção 3: Com Node / npx
```bash
npx serve .
```
